Рабочая папка — место, где находятся файлы проекта и где мы непосредственно вносим изменения.

Индекс — промежуточная область, куда мы помещаем изменения, которые хотим включить в следующий коммит.

Коммит — сохранённая версия изменений в Git с описанием того, что было изменено.



git diff

Показывает изменения в рабочей директории.

То есть изменения, которые ты сделал, но ещё не добавил в staging.

Используется до git add.

Позволяет посмотреть, что именно изменилось в файлах.

Не показывает изменения, которые уже находятся в staging.

git diff --staged

Показывает изменения, находящиеся в staging.

То есть изменения, которые уже были добавлены командой git add.

Используется перед git commit, чтобы проверить будущий коммит.

Показывает, что именно попадёт в следующий коммит.

После git commit эти изменения исчезнут из git diff --staged.

Использованные команды

git status показывает текущее состояние репозитория: изменённые, добавленные в staging и неотслеживаемые файлы.

git diff показывает изменения, которые ещё не добавлены в staging.

git diff --staged показывает изменения, которые уже добавлены в staging и попадут в следующий коммит.

Ветка это отдельная линия разработки проекта, которая позволяет работать над изменениями независимо от других веток.

При создании нового коммита ветка и начинает указывать на новый коммит.

Слияние объединяет изменения из одной ветки с другой, добавляя их историю в текущую ветку.
