\- git diff — показывает различия между версиями файлов: что добавили, удалили или изменили.

\- git show — показывает информацию о конкретном коммите: автора, дату, сообщение и изменения в файлах.

\- git log — показывает историю коммитов проекта: кто, когда и какие изменения вносил.

\- git log -S"текст" — находит коммиты, в которых изменилось количество вхождений указанного текста в файлах. Помогает выяснить, когда строка была добавлена или удалена.

\- git blame файл — показывает для каждой строки файла последний коммит, в котором она была изменена, а также автора и дату изменения.

Главное отличие: diff сравнивает версии, show показывает конкретный коммит, log отображает историю, log -S ищет изменения конкретного текста, а blame помогает установить, кто и когда изменил определённые строки.
